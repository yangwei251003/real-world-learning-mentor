## 为什么没有“借鉴一整套平台”

通用学习导师的价值在课堂行为和证据闭环，而不在把任何开源平台部署到本机。完整 LMS、题库、用户账号、云数据库、课程编辑器、自动化烧录和复杂 Agent 框架都会扩大依赖、降低可维护性，并掩盖 V1 是否真能教会用户。V1 只保留能直接帮助形成能力的最小机制。

## 重新实现的工程规则

1. 不向本项目拷贝任何上游源代码、Prompt、课程正文、题目、测试、图片、商标或用户数据。
2. 对“看起来可直接用”的素材，先查**具体文件**而不是只看仓库根许可证；无清晰许可即拒绝。
3. 借鉴后必须能用自己的需求、数据结构和测试解释其存在；若做不到，删除。
4. 每项借鉴必须映射至少一个 `requirements-synthesis.md` 中的 R 编号，并在测试中有可观察验证。
5. 任何将来复制、分发、发布或连接第三方实现的提议都需重新做许可证审查；本日志不是永久授权。

## 本轮未采用但有价值的提醒

- `openai/skills` 仓库页面现在标明 deprecated；本项目以当前官方 Build skills 文档与本机 Skill Creator 为准。
- Open edX 和 Anki 展示了成熟系统的价值，同时也说明 V1 不应吸收 AGPL 代码或升级为完整 LMS/复习应用。
- freeCodeCamp 的大规模课程数据和挑战生态不适合复制到个性化、跨领域、连续对话式导师；只保留“可验证任务”这一抽象。
