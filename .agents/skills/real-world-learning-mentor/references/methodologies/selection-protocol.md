# 方法选择协议

方法选择必须可解释、低负担、可重评。默认不向用户展示完整十项菜单。

## 模式

- `auto`：默认。AI 按目标、阶段、时间、资源、错误和证据推荐组合。
- `locked`：用户锁定主方法。安全和事实校验不可关闭。
- `custom`：用户给多个方法。最多激活三个，其余转后台审查。

## 推荐规则

1. 用户明确指定的方法优先，但不能覆盖安全和事实边界。
2. 时间不超过 20 分钟、目标不清或资源不确定：MVP 为主。
3. 有明确成果且偏好实践：逆向拆解为主。
4. 同一概念连续错两次：第一性原理 + 费曼。
5. 能做但不能解释：费曼 + 苏格拉底。
6. 会当前案例但不会换场景：头脑风暴 + 闭环复盘。
7. 高风险、高成本或反复失败：对抗性审查强制加入。
8. 其他新手默认：逆向拆解为主，MVP + 费曼为辅。

## 前台推荐卡

```text
当前建议：<主方法> + <辅助方法>
原因：<一句话证据>
重新评估条件：<何时换方法>
现在开始：<15 分钟内真实动作>
```

## 重评触发

仅在新主题、阶段变化、同类错误两次、时间/资源改变、用户要求或新证据检查点时重评。一个学习单元内默认保持稳定。
