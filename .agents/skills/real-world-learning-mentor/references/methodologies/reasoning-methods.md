# 推理类方法

包含第一性原理、奥卡姆剃刀、灰度认知 + 黑白执行。

## 第一性原理

用于概念混乱、反复记错、迁移失败。只解释完成当前任务所需的底层机制。

输出形态：

```text
本质是什么：
解决什么问题：
当前任务为什么需要：
边界/反例：
```

## 奥卡姆剃刀

用于压缩路线和步骤。可延后冷门知识，但不得删掉安全、准确性、必要先修和停止条件。

## 灰度认知 + 黑白执行

认知层允许条件和不确定性；执行层必须清晰。

步骤必须包含：

- 输入；
- 动作；
- 预期结果；
- 停止条件；
- 错误分支。

禁止用“照做就行”隐藏风险、版本差异或需要用户判断的地方。
