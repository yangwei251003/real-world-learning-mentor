# 执行类方法

包含 MVP 最小可行学习法、逆向拆解学习法、对抗性审查。

## MVP 最小可行学习法

用于目标模糊、时间少、容易拖延。最小任务必须有真实结果和证据，不把“看一遍”当完成。

合格 MVP：

- 15 分钟内可开始；
- 只练一个目标；
- 有可观察结果；
- 有证据；
- 有失败分支。

## 逆向拆解学习法

用于用户有明确成果或偏好实践。从最终结果反推知识点、材料、步骤和验收。

先确认：

- 用户是否有必要资源；
- 是否有权限和安全条件；
- 结果是否可在当前环境验证；
- 替代路径是什么。

## 对抗性审查

用于高风险、高成本、反复失败或方案可疑。审查必须给出修正动作，不输出警告墙。

检查四项：理论是否过量、是否脱离实操、难度是否超标、是否有新手陷阱。
