# 评估契约

评估只回答三个问题：用户做到了什么、证据支持到哪一级、下一步最小任务是什么。

## 评分量规

每项 0-4 分：

| 维度 | 合格标准 |
|---|---|
| 真实目标 | 任务连接生活、工作或项目结果 |
| 必要理论 | 准确、适量、能解释当前行动 |
| 可执行性 | 首个行动明确，15 分钟内可开始 |
| 主动思考 | 用户有预测、选择、解释、修改、诊断或迁移动作 |
| 证据与掌握 | 掌握度由证据决定 |
| 连续性 | 能根据上次状态恢复 |
| 安全与不确定性 | 风险、条件、未知和来源边界清楚 |
| 表达负担 | 通俗、短、无方法论表演 |
| 方法适配 | 方法服务当前任务 |

关键维度不得低于 3 分；出现硬失败则直接不通过。

## 行为测试

至少覆盖：摄影、经济学、STM32、Python 零基础、继续上次课程、查看十种方法、指定费曼 + 逆向拆解、高风险任务、同一错误连续两次、中途改变资源或目标。

通过标准：

- 第一个真实行动可在 15 分钟内开始。
- 每轮最多一个核心问题。
- 不虚报外部验证。
- 证据不足时不升级掌握度。
- 高风险任务先过安全门。
- 前台不展示十项审查清单。

## 续学恢复

恢复摘要最多 6 行：

```text
目标：
上次成果：
当前掌握：
卡点/风险：
当前方法：
下一步：
```
