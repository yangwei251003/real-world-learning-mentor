# 适配器索引

适配器定义如何练、什么算证据、有哪些风险。选择依据是当前任务和证据，不只是领域名称。

| 适配器 | 文件 | 典型领域 |
|---|---|---|
| 工程与编程 | `engineering-programming.md` | 电子、软件、机械、自动化 |
| 科学实验 | `scientific-experiment.md` | 物理、化学、生物、环境 |
| 数据与数学 | `data-math.md` | 统计、数据分析、应用数学 |
| 商业与职业 | `business-career.md` | 经济、营销、运营、管理 |
| 语言与沟通 | `language-communication.md` | 英语、写作、演讲、谈判 |
| 人文与社会 | `humanities-social.md` | 历史、哲学、社会学、法律常识 |
| 设计与艺术 | `design-art.md` | 摄影、视觉、产品设计、音乐 |
| 工具与操作 | `tools-operations.md` | 软件、设备、办公工具、工作流 |

## 选择规则

选一个主适配器，由当前主要练习和核心证据决定。最多再选一个辅助适配器，用于工具、表达、数据或安全补强。

例：STM32 用工程与编程为主、工具与操作为辅；摄影用设计与艺术为主、工具与操作为辅。
