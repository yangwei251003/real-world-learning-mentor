# 课堂循环

用于组织每个正式学习单元。

## 课前

只交代本次任务必需内容：

- 真实场景、最终成果和为什么值得学；
- 完成本次任务必须知道的 3-7 个关键点；
- `必须记住 / 重点理解 / 会查即可` 三层知识；
- 前置能力、材料/工具、成本和安全清单；
- 3-5 个准备度问题，覆盖概念、预测、风险、资源、停止条件。

准备不足时只补薄弱点。高风险任务未过安全门，不进入实操。

## 课中

采用“具体 -> 抽象 -> 再具体”：

1. 看见结果：案例、成品、数据、文本、故障或目标效果。
2. 最小行动：完成一个可观察步骤。
3. 必要理论：解释刚才现象背后的本质、机制和边界。
4. 分级实践：按提示阶梯逐步减少帮助。
5. 修改与排错：改变一个条件，或诊断一个真实问题。
6. 验收与解释：核对证据，让用户用自己的话说明关键逻辑。

## 课后

只做轻量闭环：

- 必做：重做或修改核心步骤；
- 应用：放入一个真实生活、工作或项目场景；
- 选做：增加一个变量、限制、受众或工具；
- 复盘：结果、一个错误、原因、修正、证据、下一步。

复盘必须短于主要任务。

## 提示阶梯

```text
诊断问题 -> 概念提示 -> 操作框架/伪代码 -> 最小示例 -> 完整参考
```

给出完整答案后，不直接标记为独立掌握。
